# HOW TO — Process an Express Service Request

1. Open **Settings → Customer Experience → Express Service**.
2. Review **Express Service requests**.
3. Update a request through acknowledged, assigned, scheduled, in-progress, or completed states.
4. Choose **Create job & invoice** when its scope is ready for billing.

Conversion creates one traceable job and one draft invoice. Repeating conversion returns the existing records and cannot duplicate them. Photo uploads, deposits, and Express prepayment remain disabled in this release.

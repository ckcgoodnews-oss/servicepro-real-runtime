# HOW TO — Send a Payment Link

1. Open **Billing → Invoices and refunds**.
2. Find an invoice with an outstanding balance.
3. Choose **Copy payment link**.
4. Paste the copied link into an approved customer communication.

Links expire after 14 days by default. Creating another link replaces the stored token. Only a token hash is stored. Expired, altered, disabled-payment, and already-paid links are rejected by the server.

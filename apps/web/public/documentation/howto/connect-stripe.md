# Connect Stripe

Only an owner or administrator with **Connect Stripe** permission can perform this action.

1. Open **Settings → Customer Payments**.
2. Select **Connect Stripe**.
3. Complete Stripe's Express onboarding form. ServicePRO does not receive or store your bank, card, or identity documents.
4. Return to Customer Payments and review **Status**, **Charges**, and **Payouts**.
5. If Stripe requires additional information, select **Continue Stripe setup**.

Customer funds are created on the connected account using Stripe's connected-account header. They are not charged on Aardvark's ServicePRO subscription account.

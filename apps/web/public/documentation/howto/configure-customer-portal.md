# HOW TO — Configure Customer Portal

1. Open **Settings → Customer Experience → Customer Portal**.
2. Enable or disable the portal.
3. Set the portal name, welcome title, and welcome message.
4. Choose whether customers can see invoices, payment actions, and estimates.
5. Enable profile or communication-preference editing only when desired.
6. Choose **Save portal settings**.

The API always limits portal records to the authenticated tenant and customer; visibility controls do not replace ownership checks.

## Maintenance

This document reflects capabilities evidenced in the repository source code. Feature availability labels follow this classification:

- **Available** — Implemented and production-ready with routes, services, and UI
- **Configurable** — Available with tenant-level or environment-level configuration options
- **Enterprise Option** — Available under enterprise tier or requires additional enablement
- **Preview** — Implemented with API routes but UI or workflows may be limited
- **Planned** — Designed and specified but not yet fully implemented in repository
- **Integration Dependent** — Requires external service connection to function

Update this document when new features ship or availability status changes.
